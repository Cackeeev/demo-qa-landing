# QA AI — AI-помощник тестировщика

Первый этап pet-project: адаптивный landing page на Java 21, Spring Boot 3.5.16,
Maven, HTML, CSS и Vanilla JavaScript. Spring Boot отдаёт статические файлы;
Java REST API, база данных, авторизация и настоящая AI-модель пока не подключены.

## Запуск

Нужны JDK 21 и Maven 3.6.3 или новее. Проверьте `java -version` и `mvn -version`:
обе команды должны использовать Java 21. При необходимости задайте `JAVA_HOME`
на каталог установленного JDK 21 и добавьте `$JAVA_HOME/bin` в `PATH`.

Из директории проекта:

```sh
mvn clean package
java -jar target/qa-ai-0.0.1-SNAPSHOT.jar
```

Открыть **http://localhost:8080**. Остановить приложение — `Ctrl+C`.
Альтернативный запуск для разработки: `mvn spring-boot:run`.
При изменении HTML/CSS/JS перезапустите приложение; при запуске JAR сначала
соберите его заново. Если порт 8080 занят, остановите ранее запущенный экземпляр.

## Файлы

- `pom.xml` — версия Java, Spring Boot, зависимость web и упаковка запускаемого JAR.
- `src/main/java/org/example/Application.java` — точка входа Spring Boot.
- `src/main/resources/static/index.html` — девять секций landing page.
- `src/main/resources/static/css/style.css` — тёмная тема, карточки и адаптивные стили.
- `src/main/resources/static/js/app.js` — переключение demo-сценариев, FAQ и мобильное меню.
- `src/main/resources/static/favicon.svg` — локальная иконка сайта.

## Поведение demo

Demo предлагает шесть готовых сценариев: изменение email и пароля, регистрацию,
авторизацию, восстановление пароля и изменение профиля. Выбор сценария показывает
соответствующие тест-кейсы и потенциальные проблемы. Настоящий AI не подключён;
данные не отправляются на сервер и не сохраняются в localStorage.
Цифры в блоке статистики иллюстративные, а не измеренные показатели продукта.

Внешние шрифты, frontend-библиотеки и аналитика не используются. Ссылка GitHub
ведёт на родительский репозиторий `Cackeeev/demo-qa-autotests`.
